# What-if...

Stell eine Frage hinter **What if**.

Fragen aus der Liste haben eine Erklärung, die für genau diesen Fall geschrieben ist. Für alle anderen sagt die Seite, dass sie keine geprüfte Erklärung hat. Sie zeigt, welche Grenze in diesem Satz zu finden ist und welche nicht. Liegt eine geschriebene Frage nur in der Nähe, wird sie genannt und nicht als Antwort verwendet. Die Seite erfindet keine Fakten.

Die Erklärung läuft im Browser. Die Frage wird dabei nicht an einen Dienst geschickt.

```bash
python3 -m http.server 4173
```

Dann `http://localhost:4173` öffnen.
